## Đối chiếu với thiết kế đã chốt

- **Dependency.** `envelope` (path), `serde_json` 1, `clap` 4.6.9 (derive), `ureq` 3.5.2 (rustls mặc định). Viết theo mã nguồn của `ureq` 3.5.2 trong registry: `Agent::config_builder().http_status_as_error(false).timeout_global(Some(30s))`, `response.status().as_u16()`, `body_mut().read_to_string()`.
- **Mã trạng thái không phải lỗi truyền tải.** Đã tắt `http_status_as_error`, nên 4xx/5xx đi vào hàm ánh xạ. Đã kiểm thật bằng một listener Python cục bộ (không gọi Worker đã deploy): 201, 200, 400, 401, 403, 500 đều ra đúng đầu ra và mã thoát.
- **Cấu hình.** `--server` ghi đè `OS_WIDGET_SERVER`; dấu `/` cuối bị bỏ trước khi nối `/items`. Token chỉ từ `OS_WIDGET_PUBLISH_TOKEN`; không có cờ `--token` (có test).
- **Hai cách đưa nội dung.** `--file` có `conflicts_with_all` với tám cờ `notification`; `--source`, `--title`, `--summary` có `required_unless_present = "file"`. Dùng `--link`, không có `--url` (có test). JSON dựng từ cờ đi qua cùng `envelope::parse` như file.
- **`--dry-run`.** Validate rồi in envelope đã chuẩn hoá (JSON thụt lề), không đọc cấu hình, không gọi mạng.
- **Thứ tự.** Validate trước cấu hình, nên envelope sai luôn thoát 2 kể cả khi thiếu `OS_WIDGET_SERVER`.
- **Thứ được gửi.** Gửi envelope đã chuẩn hoá (`serde_json::to_vec(&envelope)`), tức đúng thứ `--dry-run` in ra. Test xác nhận dạng chuẩn hoá parse lại ra cùng giá trị, kể cả `notification` không có `body` (được gửi thành `"body": null`).

## Kiểm thủ công `--dry-run`

File `vocab` hợp lệ:

```
$ cargo run -q -p cli -- publish --dry-run --file vocab-ok.json
{
  "v": 1,
  "kind": "vocab",
  "body": { "word": "serendipity", ..., "meanings": [ { "definition": "the occurrence of events by chance in a happy way", ... } ], ... },
  ...
  "dedupe_key": "vocab-2026-11-23T10"
}
exit=0
```

Cùng file bỏ `definition`:

```
$ cargo run -q -p cli -- publish --dry-run --file vocab-broken.json
invalid envelope: body.meanings[0]: missing field `definition`
exit=2
```

Thêm: `--file -` từ stdin thoát 0; dựng từ cờ có `--text`, `--link` thoát 0; publish thật khi thiếu `OS_WIDGET_SERVER` in `missing server URL: set OS_WIDGET_SERVER or pass --server` và thoát 1.
